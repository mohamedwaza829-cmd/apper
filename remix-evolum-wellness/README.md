## 1. نظرة عامة على التطبيق (Executive Overview)

**Evolum Wellness** هو تطبيق متكامل للصحة النفسية والجسدية واليقظة الذهنية (Mindfulness & Somatic Wellness)، صُمم ليكون واحة رقمية تجمع بين:
- **العلاج الطبيعي والتأمل الموجه** لخفض مستويات الكورتيزول والتوتر.
- **تتابعات اليوغا الحركية المصحوبة بمرشد بصري دقيق** ورسوم بيانية متحركة لكل وضعية.
- **تمارين التنفس العلمي وموازنة الجهاز العصبي اللاودي (Parasympathetic Nervous System)** مستندة إلى أبحاث هارفارد والتقاليد الشرقية العريقة.
- **محرك صوتي تركيبي حي (Web Audio API Synthesizer)** يولد ترددات سولفيجيو الشفائية ونبضات بكلتا الأذنين (Binaural Beats) لحظياً دون الحاجة لملفات صوتية ضخمة مسجلة مسبقاً.
- **مرشد صحي مدعوم بالذكاء الاصطناعي (Gemini 3.5 Flash)** ومحرك نطق فائق (Gemini 3.1 Flash TTS) مع دعم الترجمة الفورية الصوتية المزدوجة (Live Simultaneous Voice Translate).
- **دعم كامل للغتين (العربية والإنجليزية)** مع مراعاة اتجاه النصوص وتناسق الخطوط (RTL & LTR).

## 2. فلسفة التصميم والهوية البصرية (Design System & UI/UX)

### 2.1 المفهوم الجمالي (Visual Aesthetics)
- **إطار العرض المحمول المريح (Mobile-First Ergonomics):** تم تأطير التطبيق داخل مساحة مركزية أنيقة مع حواف دائرية انسيابية (`rounded-3xl`) وظلال ناعمة متعددة الطبقات لتوفير تجربة تشبه تطبيقات الهواتف الذكية الراقية على الشاشات الكبيرة والصغيرة.
- **الهدوء البصري ونبذ الضوضاء (Visual Serenity):** الاعتماد على ألوان مريحة للعين، تدرجات باستيل مدروسة، وتوزيع مريح للمسافات البيضاء يمنع التشتت والإرهاق الذهني.

### 2.2 لوحة الألوان (Color Palette & Theming)
- **الوضع الفاتح (Light Mode):** خلفيات بألوان حيادية دافئة (`bg-gray-50`، `bg-white`) مع عناصر متدرجة هادئة من الأزرق السماوي (`Sky`)، البنفسجي الفاتح (`Violet`)، الزمردي (`Emerald`)، والوردي المهدئ (`Rose`).
- **الوضع الداكن (Dark Mode):** أسود ليلي عميق (`bg-gray-900`، `bg-gray-850`) لحماية العين أثناء الاستخدام الليلي أو قبل النوم، مع الحفاظ على تباين لوني مريح ومتوافق مع معايير الوصولية WCAG AA.
- **ألوان المؤشرات والحالات:**
  - الأزرق والنيلي (`#3B82F6` / `#6366F1`): التركيز والاتزان والصفاء.
  - البنفسجي واللافندر (`#8B5CF6` / `#A78BFA`): التأمل العميق وتناغم الشاكرات.
  - الزمردي والتيل (`#10B981` / `#14B8A6`): الشفاء، تقليل التوتر، والصمود.
  - العنبري والذهبي (`#F59E0B` / `#EAB308`): الطاقة، شارات الإنجاز، واكتمال الأهداف.

### 2.3 الطباعة وتناسق النصوص (Typography & Layout)
- استخدام خطوط متوافقة مع القراءة السلسة على الشاشات بدقة بصرية متوازنة.
- نسب تباعد أسطر واسعة ومريحة (1.5 إلى 1.7) تضمن راحة العين أثناء قراءة التعليمات والتوكيدات اليومية.
- دعم كامل للغة العربية مع ضبط أوزان الخطوط، وعلامات الترقيم، والأرقام المشرقية في سياقات التوقيت.

### 2.4 الرسوم المتحركة والحركية (Micro-interactions & Motion)
- تكامل محرك `motion/react` في جميع الانتقالات بين الشاشات، وفتح الجلسات المنبثقة، وتدرجات الضوء النابضة في مؤقت التنفس والمشغل الصوتي.
- تموجات بصرية حية (Pulsing Rings) تتزامن مع الشهيق والزفير، ما يمنح المستخدم دليلاً بصرياً طبيعياً للتنفس دون الحاجة لمراقبة الأرقام.

## 3. البنية التقنية والمعمارية (Architecture & Tech Stack)

```
┌────────────────────────────────────────────────────────┐
│                   Frontend (Client)                    │
│  React 18 + TypeScript + Vite + Tailwind CSS + Motion   │
│  Recharts (Data Viz) + Lucide Icons + Web Audio API     │
└──────────────────────────┬─────────────────────────────┘
                           │ API Requests (JSON / Audio)
┌──────────────────────────▼─────────────────────────────┐
│                   Backend (Server)                     │
│  Express.js (Node.js) on Port 3000                     │
│  Vite Development Middleware / Static Production SPA   │
└──────────────────────────┬─────────────────────────────┘
                           │ SDK Calls
┌──────────────────────────▼─────────────────────────────┐
│                 Google Gemini API                      │
│  - gemini-3.5-flash: Mood Analysis & Conversational AI │
│  - gemini-3.1-flash-tts-preview: Neural Vocal Speech   │
└────────────────────────────────────────────────────────┘
```

- **الواجهة الأمامية (Frontend):**
  - **المكتبات:** React 18، TypeScript، Vite.
  - **التنسيق:** Tailwind CSS الإصدار الحديث المدمج مع Vite.
  - **الحركة والرسوم:** `motion/react` لتوفير انتقالات انسيابية وتفاعلات اللمس.
  - **الرسوم البيانية:** `recharts` لعرض تتبع الأيام المتتالية وسجل التنفس.
  - **الأيقونات:** `lucide-react` بالإضافة إلى مكتبة رسومات SVG مخصصة تم بناؤها يدوياً لوضعيات اليوغا.
- **الواجهة الخلفية (Backend & APIs):**
  - سيرفر Express.js مدمج يعمل على المنفذ الموحد 3000.
  - نقاط نهاية آمنة (`/api/generate-wellness`, `/api/chat-wellness`, `/api/generate-audio`, `/api/voice-chat-live`).
- **محرك الصوت المدمج (Native Web Audio Engine):**
  - فئة برمجية متطورة `SessionSynthesizer` داخل `src/utils/audioManager.ts` تدير شبكة عقد صوتية معقدة (Oscillators, GainNodes, BiquadFilterNodes, Stereo Channel Mergers) لتوليد نغمات وموجات دماغية في الوقت الفعلي.

## 4. دليل الشاشات وواجهات المستخدم (Screens & Navigation)

### 4.1 شاشة البداية والتحميل (Splash Screen)
- **العناصر:** شعار Evolum المتحرك بنبضات انسيابية متدرجة (`#A78BFA` إلى `#3B82F6`) مع نص "جاري تحميل هدوئك..." ومؤشر تقدم لطيف.
- **التفاعل:** انتقال تلقائي سلس بعد 3 ثوانٍ إلى شاشة الترحيب أو الشاشة الرئيسية.

### 4.2 شاشات التعريف والتوجيه (Onboarding Carousel)
- تتألف من 3 شرائح تفاعلية مدعومة برسوم متجهية SVG متحركة:
  1. **الشريحة الأولى (ابحث عن هدوئك الداخلي):** تركز على جلسات التأمل واليوغا المصممة للراحة النفسية.
  2. **الشريحة الثانية (تتبع تقدمك بسهولة):** تعرض مؤشرات الأداء البيانية وسهولة مراقبة العادات.
  3. **الشريحة الثالثة (انضم إلى مجتمعنا):** تدعو المستخدم لبدء رحلته فوراً.
- **الأزرار:** أزرار "التالي" و"تخطي" و"ابدأ الآن" مع مؤشرات النقاط السفلية الحركية.

### 4.3 الشاشة الرئيسية (Home Screen)
- **الترويسة والترحيب:** عرض اسم المستخدم مع شارة تحفيزية لليوم الحالي وزر البحث الفوري المباشر.
- **توكيد اليوم الإيجابي (Daily Affirmations):** بطاقة تفاعلية مميزة متصلة بمحرك توكيدات يعرض رسائل الامتنان، حب الذات، الصمود، والتفاؤل مع إمكانية التحديث التلقائي الفوري (`Refresh`).
- **بطاقة "تابع من حيث توقفت" (Continue Where Left Off):** تظهر تلقائياً عندما يغادر المستخدم جلسة قبل إكمالها، مع شريط تقدم يوضح النسبة المئوية المتبقية وزر استئناف فوري.
- **اقتراح اليوم المخصص (Suggested For You):** جلسات مميزة تم اختيارها بناءً على الوقت والهدف.
- **بطاقة المرشد الذكي (AI Coach Banner):** مدخل مباشر للتحدث مع المرشد المدعوم بالذكاء الاصطناعي وتوليد التمارين الخاصة.

### 4.4 شاشة التأمل (Meditation Screen)
- **شريط الفلاتر والتصنيفات:** أزرار تصنيف تتيح التصفح حسب: (الكل، التركيز، الاسترخاء، النوم، تقليل التوتر).
- **أداة تمرين التنفس السريع:** بطاقة متقدمة مدمجة تشجع على بدء جولات التنفس فوراً وعرض عدد الدورات المنجزة من الهدف اليومي.
- **شبكة الجلسات (Sessions Grid):** بطاقات تفاعلية تعرض اسم الجلسة باللغتين، المدة بالدقائق، التدرج اللوني الجذاب، وخلفيات بصرية مهدئة، مع مؤشر لحفظ الجلسة في المفضلة.

### 4.5 شاشة اليوغا (Yoga Screen)
- **فلاتر المستويات الحركية:** (مبتدئ، متوسط، متقدم).
- **بطاقات الجلسات الحركية:** تعرض مستوى الصعوبة، الوقت الإجمالي، وتصنيف التدفق.
- **معاينة الوضعيات:** إمكانية النقر على أي جلسة لاستعراض الوضعيات المضمنة فيها مع الرسوم التشريحية قبل بدء التمرين.

### 4.6 شاشة مؤقت التنفس التفاعلي (Interactive Breathing Timer)
- حلقة دائرية مضيئة ثلاثية الطبقات تنبض بالحياة مع كل مرحلة من مراحل التنفس:
  - **الاستعداد (Prepare)**
  - **الشهيق (Inhale)**
  - **حبس النفس (Hold)**
  - **الزفير (Exhale)**
- مقياس رقمي للثواني المتبقية مع شريط تقدم محيطي متصل بالكامل.
- مبدل التقنيات الست الكلاسيكية والعالمية.
- مؤشر تحقيق الهدف اليومي (Daily Goal Progress Bar).

### 4.7 شاشة المشغل الصوتي التفاعلي (Player Screen & Sound Mixer)
- **مؤقت العد التنازلي الدائري:** مع زر التشغيل/الإيقاف المؤقت وأزرار التقديم والتأخير.
- **لوحة تمازج الأصوات الحية (Ambient Sound Mixer):** لوحة تحكم منبثقة بمستويات صوت مستقلة لأربعة مسارات:
  1. مسار نغمات السكينة والوسائد الموسيقية (Mindfulness Ambient Pad).
  2. مسار ترددات الشفاء والموجات الثنائية (Solfeggio & Binaural Beats).
  3. مسار محاكاة التنفس وأمواج المحيط (Respiration & Nature Ocean Wave).
  4. مسار أجراس اليقظة والصفاء الذهني (Mindfulness Temple Chimes).
- **مبدل ترددات سولفيجيو الحي:** يسمح باختيار التردد المستهدف أثناء تشغيل الجلسة (مثل 432Hz للوضوح أو 528Hz لتحفيز الطاقة).
- **قائمة التشغيل المتتالية (Continuous Queue):** تمكّن المستخدم من إضافة عدة جلسات متتابعة للتأمل واليوغا مع ميزة التخطي للجلسة التالية دون توقف.
- **عارض الوضعيات التفاعلي في جلسات اليوغا:** يعرض رسم الوضعية الحالية، فوائدها العصبية والجسدية، خطوات المحاذاة، والوضعية التالية في التسلسل.

### 4.8 شاشة تفاصيل الجلسة (Session Details Screen)
- نظرة عامة قبل التشغيل، تشمل:
  - المدة الزمنية الدقيقة والتصنيف.
  - قائمة الفوائد المتوقعة من إتمام الجلسة.
  - زر الإضافة إلى المفضلة وزر البدء الفوري.
  - استعراض الوضعيات التفصيلية في حال كانت جلسة يوغا.

### 4.9 شاشة المرشد الذكي الصوتي (AI Coach Screen)
- واجهة مزدوجة تجمع بين وضعين:
  1. **المحادثة الصوتية الحية المباشرة (Gemini Live Voice & Translate):** ميكروفون تفاعلي نابض يستمع لصوت المستخدم أو يستقبل الاختصارات السريعة ليرد بصوت بشري هادئ مع ترجمة فورية ثنائية متزامنة (عربي/إنجليزي).
  2. **صانع الجلسات المخصصة والتأمل الذكي:** تحديد المشاعر الحالية (متوتر، قلق، متعب، حزين، غاضب، مستقر) والهدف المطلوب، ليقوم Gemini بتوليد جلسة فريدة تتضمن خطوات عملية ونصيحة ملهمة وصوتاً موجهاً.

### 4.10 شاشة التقدم والتحليلات (Progress & Analytics Dashboard)
- **بطاقات الإحصائيات الأربعة الرئيسية:**
  - عدد الأيام المتتالية (Day Streak) مع أيقونة الشعلة التحفيزية.
  - عدد الجلسات المكتملة (Sessions Completed).
  - إجمالي دقائق التأمل المسجلة (Minutes Meditated).
  - إجمالي دورات التنفس المنجزة (Breathing Cycles).
- **سجل نشاط الأسبوع (Weekly Activity Tracker):** دوائر مضيئة لكل يوم من أيام الأسبوع توضح التزام المستخدم اليومي.
- **مستوى الاستمرارية والاتزان (Mindfulness Consistency Meter):** تصنيف تفاعلي للمستخدم (مبتدئ، ملتزم، خبير زن) مع شريط تقدم للوصول للمستوى التالي.
- **مخطط مساحة دورات التنفس (AreaChart):** يوضح اتجاهات التنفس الأسبوعية على مدار آخر 30 يوماً بتدرج بنفسجي انسيابي.
- **مخطط خطي لمقارنة الاستمرارية (LineChart):** يقارن أداء الأيام المتتالية لآخر 30 يوماً مقارنة بالشهر السابق لتحفيز العزيمة.

### 4.11 شاشة الملف الشخصي والشارات (Profile & Badges Screen)
- الصورة الشخصية للمستخدم مع شارة نوع العضوية وإجمالي الجلسات المكتملة.
- زر الترقية إلى باقة المحترفين (Upgrade to Pro).
- **نظام شارات الإنجاز والأوسمة (Achievement Badges Grid):** بطاقات شارات ملوّنة تتفتح تلقائياً عند تحقيق الأهداف مع تفاصيل متكاملة وإمكانية مشاركة الإنجاز.
- قائمة الإعدادات السريعة، المفضلة، التذكيرات، وتسجيل الخروج.

### 4.12 شاشة الإعدادات والتخصيص (Settings Screen)
- **بيانات الملف الشخصي:** الاسم، العمر، الجنس، الطول، الوزن، والهدف الشخصي.
- **الهدف اليومي للتنفس:** اختيار عدد الدورات المستهدفة (4، 8، 12، 16، أو 20 دورة).
- **المظهر (Appearance):** التبديل بين المظهر الفاتح (Light)، الداكن (Dark)، وتلقائي بحسب النظام (System).
- **تذكيرات الصحة الذكية (Notifications):** مفاتيح تشغيل لتذكير شرب الماء، تذكير الوجبات الصحية، وتذكير التمارين اليومية.
- **اللغة:** التبديل الفوري بنقرة واحدة بين العربية والإنجليزية.
- **الاشتراكات:** إدارة بطاقة Evolum Premium.

### 4.13 شاشات البحث، المفضلة، واكتمال الجلسة
- **البحث اللحظي (Real-Time Search):** حقل بحث سريع يبحث فورياً في عناوين وتفاصيل الجلسات بالعربية والإنجليزية مع إبراز النتائج المطابقة.
- **المفضلة (Favorites):** نافذة مخصصة تضم كافة الجلسات المحفوظة بنقرة زر واحدة لتسهيل العودة إليها.
- **شاشة الاحتفال بإتمام الجلسة (Session Complete Celebration):** شاشة تظهر بعد نهاية الوقت بمؤثرات احتفالية وعبارات تهنئة تحفز الإنجاز مع زر العودة للصفحة الرئيسية.

## 5. محتوى مكتبة التأمل الواعي (Meditation Library)

تحتوي مكتبة التأمل على 5 جلسات مصممة بعناية فائقة تلبي مختلف الاحتياجات النفسية والجسدية:

| المعرف (ID) | عنوان الجلسة (عربي) | عنوان الجلسة (إنجليزي) | المدة | التصنيف | التردد الصوتي الأساسي | الموجة الدماغية | التدرج اللوني |
|---|---|---|---|---|---|---|---|
| `m1` | **تنفس الصباح** | *Morning Breath* | 5 دقائق | التركيز (`focus`) | 432 Hz (الطبيعي والصفاء) | موجات ألفا (Alpha - 10Hz) | `from-sky-200/50 to-blue-300/50` |

## 6. محتوى مكتبة وتتابعات اليوغا (Yoga Library & Postures)

تضم المكتبة 4 مسارات يوغا متكاملة بإجمالي 16 وضعية تفصيلية، مدعومة بكل من:
1. الاسم بالعربية والإنجليزية والمصطلح السنسكريتي الأصيل.
2. التوقيت الدقيق لكل وضعية.
3. الفوائد الجسدية والعصبية.
4. إرشادات المحاذاة والخطوات الحركية.
5. رسومات SVG مخصصة ومتوهجة تمثل الهيكل التشريحي للوضعية.

### 6.1 الجلسة الأولى (`y1`): يوغا الصباح للمبتدئين (*Morning Yoga for Beginners*)
- **المدة الإجمالية:** 15 دقيقة | **المستوى:** مبتدئ (`beginner`) | **اللون:** وردي ناعم (`from-rose-200/50 to-pink-300/50`)
- **الوضعيات:**
  1. **وضعية الطفل (بالاسانا - Balasana):** (3 دقائق) — إرخاء العمود الفقري، تقليل التوتر العضلي، وضبط ريتم التنفس.
  2. **وضعية القطة والبقرة (مارجارياسانا - Marjaryasana):** (4 دقائق) — ليونة الظهر، تدفئة الفقرات القطنية، وزيادة مساحة الاستنشاق.
  3. **وضعية الكلب المتجه لأسفل (أدهو موخا - Adho Mukha):** (4 دقائق) — تمديد الجسم بالكامل، تقوية الأكتاف وتنشيط الدورة الدموية.
  4. **وضعية الكوبرا (بوجانغاسانا - Bhujangasana):** (4 دقائق) — فتح الصدر، تنشيط طاقة الرئتين، وتقوية عضلات الظهر والذراعين.

### 6.2 الجلسة الثانية (`y2`): تدفق الطاقة (*Energy Flow*)
- **المدة الإجمالية:** 25 دقيقة | **المستوى:** متوسط (`intermediate`) | **اللون:** برتقالي مفعم بالحيوية (`from-orange-200/50 to-amber-300/50`)
- **الوضعيات:**
  1. **تحية الشمس (سوريا ناماسكار - Surya Namaskar):** (6 دقائق) — تحفيز حرق الطاقة والتمثيل الغذائي وتجديد طاقة الخلايا.
  2. **وضعية المحارب الثاني (فيرابادرانا 2 - Virabhadrasana II):** (6 دقائق) — بناء الثبات والقوة في عضلات الفخذين وتنمية التوازن الاستراتيجي للجسد.
  3. **وضعية المثلث (تريكوناسانا - Trikonasana):** (6 دقائق) — تمديد ممتاز للعمود الفقري والمضخات الليمفاوية بالجانبين.
  4. **وضعية نصف القمر (أردها شاندراسانا - Ardha Chandrasana):** (7 دقائق) — موازنة الجملة العصبية وتقوية عضلات الكاحل والخصر الجانبي.

### 6.3 الجلسة الثالثة (`y3`): مرونة متقدمة (*Advanced Flexibility*)
- **المدة الإجمالية:** 40 دقيقة | **المستوى:** متقدم (`advanced`) | **اللون:** سيان وتيل (`from-teal-200/50 to-cyan-300/50`)
- **الوضعيات:**
  1. **وضعية ملك الحمام (كابوتاسانا - Kapotasana):** (10 دقائق) — فتح الحوض العميق والتحرر من الضغوط العاطفية المخزنة في الوركين.
  2. **الانقسام الكامل (هانوماناسانا - Hanumanasana):** (10 دقائق) — الوصول لمرونة كاملة للأربطة الفخذية والوركية والتحكم الجسدي المتقدم.
  3. **وضعية العجلة الكاملة (أوردفا دانوراسانا - Urdhva Dhanurasana):** (10 دقائق) — زيادة تدفق الأدرينالين والنشاط، فتح كامل للصدر والفقرات الصدرية.
  4. **وضعية حورية البحر (إيكا بادا كوبين - Mermaid Pose):** (10 دقائق) — دمج مرونة الكتفين والأكواع وعضلات الأرداف في وضعية انسيابية فائقة الجمال.

### 6.4 الجلسة الرابعة (`y4`): يوغا للاسترخاء (*Yoga for Relaxation*)
- **المدة الإجمالية:** 20 دقيقة | **المستوى:** مبتدئ (`beginner`) | **اللون:** أزرق سماوي ناعم (`from-blue-200/50 to-sky-300/50`)
- **الوضعيات:**
  1. **وضعية تأمل اللوتس (بادماسانا - Padmasana):** (5 دقائق) — تهدئة عميقة لموجات الدماغ والمساهمة في الاستغراق في النوم السريع والآمن.
  2. **وضعية الفراشة (بادا كوناسانا - Baddha Konasana):** (5 دقائق) — تخفيف التشنج في أربطة الفخذين المتوترة نتيجة الجلوس الطويل والمكتبي.
  3. **وضعية الجسر المدعوم (سيتو باندا - Setu Bandha):** (5 دقائق) — تخفيف توتر الكتفين ومحاذاة الرقبة وزفر الضغوط المتراكمة.
  4. **رفع الساقين على الحائط (فيباريتا كاراني - Viparita Karani):** (5 دقائق) — تنشيط الدورة الدموية العكسية، تجاوز التعب وإراحة عضلة القلب والشريان الأبهر.

## 8. المولد الصوتي وترددات الشفاء (Web Audio Synthesizer & Solfeggio)

يعتمد التطبيق على معمارية توليد أصوات داخل المتصفح مباشرة عبر واجهة برمجيات الصوت `Web Audio API` دون الاعتماد على ملفات MP3 خارجية ثقيلة، ما يضمن سرعة التحميل وانعدام استهلاك باقة الإنترنت.

### 8.1 القنوات الصوتية التوليدية الأربعة:
1. **قناة النغمات والموجات الحلقية (Ambient Pads):** توليد أوتار موسيقية دافئة تتألف من توافقيات رئيسية وثانوية يتم تمريرها عبر مرشح ترددات منخفضة تفاعلي (`BiquadFilterNode`) مع مذبذب تردد منخفض (`LFO`) يحاكي حركة الهواء الكوني.
2. **قناة النبضات الثنائية (Binaural Brainwave Beats):** مذبذبان نقيان (`Sine Waves`) منفصلان تماماً؛ يُرسل الأول إلى الأذن اليسرى والثاني إلى الأذن اليمنى بفارق ترددي دقيق (`Delta Freq`) لتوجيه الدماغ إلى موجات:
   - **دلتا (Delta 0.5–4 Hz):** للنوم العميق وإصلاح الخلايا.
   - **ثيتا (Theta 4–8 Hz):** للتأمل الاسترخائي وإطلاق الإبداع.
   - **ألفا (Alpha 8–12 Hz):** لليقظة الهادئة وتصفية التفكير.
   - **بيتا (Beta 12–16 Hz):** للنشاط الحركي والتركيز الرياضي.
3. **قناة أمواج الطبيعة والتنفس (Respiration & Ocean Waves):** توليد ضوضاء وردية/بيضاء (`Pink/White Noise Buffer`) يتم تعديل كسبها وفلترتها دورياً بتناغم يحاكي مد وجزر أمواج البحر ودورات الشهيق والزفير.
4. **قناة أجراس المعبد (Mindfulness Chimes):** خوارزمية مجدولة تطلق رنات أجراس نحاسية رنانة ذات تلاشٍ أسي طبيعي كل 20 إلى 45 ثانية لتذكير المستخدم بالبقاء في اللحظة الراهنة.

### 8.2 جدول ترددات السولفيجيو الشفائية المدمجة:
- **174 Hz:** تسكين الآلام الجسدية، الشعور بالأمان، وبناء قاعدة الاسترخاء (مخصص لجلسات النوم).
- **396 Hz:** التحرر من عقد الخوف، الذنب، والتوتر النفسي الحاد (مخصص للاسترخاء المسائي).
- **432 Hz:** تردد الطبيعة الكونية، يقلل ضربات القلب ويوفر الهدوء الداخلي الصافي.
- **528 Hz:** تردد التحول والترميم الخلوي وطاقة الحياة (مخصص ليوغا الصباح وتدفق الطاقة).
- **639 Hz:** تعزيز التواصل العاطفي والتناغم الداخلي ومرونة العلاقات.
- **741 Hz:** تنقية العقل من السموم الفكرية وتفكيك الإشعاعات السلبية (مخصص لتخفيف الضغوط).

  - اقتراح فوري لجلسة معينة بالاسم والرمز من مكتبة التطبيق، وتفعيل زر "ابدأ الجلسة فوراً" للمستخدم داخل المحادثة.
